# static-artifacts

Generated build artifacts. Served directly over `raw.githubusercontent.com`.

## Do not delete or rename

Files here are referenced by external services using their **full URL**. The services store the
URL, not a copy of the file — removing, renaming, or reorganising anything here breaks references
that are already live and cannot be re-pointed.

This includes "cleaning up old files": nothing here becomes unused. Append only.

The repository name is deliberately generic. What it belongs to, and why, is documented in the
originating project — not here.
